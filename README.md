# Sistema-de-Gest-o-para-Pet-Shop-V2.0-em-Python-CLI-com-MySQL
Sistema de Gestão para Pet Shop (V2.0) feito em Python (CLI). Projeto modularizado com arquitetura profissional, usando MySQL para CRUD completo de produtos, clientes, vendas, serviços e agendamentos. Possui login com perfis Admin/User, relatórios em Excel e notificações em tempo real via Bot do Telegram e e-mail (SMTP).
